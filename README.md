# Dazzlone (React)

This project is a React/Vite conversion of the original `index.html` UI (Dazzlone). It keeps the same UI and functionality while running inside a React app.

Quick start:

```bash
npm install
npm run dev
```

Notes:
- The original API key is embedded in `src/App.jsx` as `API_KEY` (you should move it to an environment variable for security).
- Static asset `Dazzlone.png` should be placed in the project root or `public/` so the app can load it.
